Built natively on Darwin arm64 with Apple clang 21.0.0 (clang-2100.1.1.101),
macOS SDK 26.5; this artifact's Mach-O minimum macOS version is 26.0.
FFmpeg and x264 are statically linked. Dynamic dependencies are only macOS
system libraries/frameworks (libSystem, libz, VideoToolbox, CoreFoundation,
CoreMedia, CoreVideo, CoreServices), not Homebrew libraries.

Rebuilding the Darwin artifact from release materials:
1. Extract ffmpeg-corresponding-source-v0.0.1.tar.gz and enter its directory.
2. Install Xcode command-line tools, make, pkg-config and nasm on Darwin arm64.
3. Run: SOURCE_DIR="$PWD/sources" bash ffi/bin/build.sh darwin-arm64
   The archive hashes are checked before extraction; no source download occurs
   when the supplied archives are present. Output: ffi/bin/ffmpeg_darwin_arm64.
4. Copy that executable to the same path in a checkout before building Go.

The script also accepts darwin-amd64 (native Intel Mac), linux-amd64 and
linux-arm64 (Docker ubuntu:22.04), and windows-amd64 (Docker
 dockcross/windows-static-x64). Those targets are source recipes only; no
binary or completed cross-platform build is claimed. Docker images and system
toolchains are not pinned; exact source/configuration is reproducible, but
byte-for-byte output across toolchains, timestamps and temporary paths is not
claimed. The script preserves the existing codec, filter, demuxer, muxer and
protocol flags. Only unused X11/XCB detection is disabled to avoid linking
unrelated Homebrew libraries. Application policy and runtime are unchanged.

Consumers of the native PureScript modules use a native backend and the Go
module github.com/i-am-the-slime/purescript-native-encoding at v0.0.1. This is
a GitHub/Go source release, not a portable PureScript registry publication.
